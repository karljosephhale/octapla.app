# octapla.app

The built site for https://octapla.app: the page that shows a passage someone shared from
Octapla (`/s#…`) and a landing page. It is generated output; do not edit it here.

Source and build: the `web/` folder of the private Octapla repository (`npm run web:build`).
It hosts only public-domain texts, one file per text per KJV chapter (`t/<code>/<Book>.<ch>.json`),
and `sources.json` with each text's attribution. It uses no cookies, no analytics and no third-party requests.
